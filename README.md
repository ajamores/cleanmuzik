# CleanMuzik

A self-hosted web app for cleaning and tagging your music library via audio fingerprinting.

## Stack

- Frontend: React + TypeScript (Vite)
- Backend: Node.js + Express
- Fingerprinting: Python + ShazamIO
- Containerisation: Docker

## Getting Started

## Run Server
./.venv/bin/uvicorn app.main:app --reload --port 8137 

## Run Frontend
npm run dev
