# T-212 — Standalone Shazam artist/title hint on the review card

**Status:** untriaged
**Found:** 2026-08-11 (T-207 design gate — payload gap, owner-decided to defer)

## Problem

Spec §4 originally called for the review card to show a **Shazam suggestion as a labelled
hint**, fed into the existing re-search / keep-untagged exits (ADR-020). It does not reach
the card. Neither transport that feeds the card carries the Shazam guess:

- `track.review_required` SSE event (`jobs.py::_emit_review_required`) carries `reason` +
  `contradictions` + candidates — no Shazam artist/title.
- Hydrated `GET /api/reviews` row (`reviews.py::_hydrate`) carries the same set plus `guess`
  — but `guess` is the **machine's search terms** (query title + staging artist tag), not
  the Shazam guess.
- T-206 persisted `reason` + `contradictions_json` only; no Shazam column.

Shazam already reaches the card in **one** place: the ISRC→MB synthetic **candidate** (spec
§5), when the ISRC resolves — but that is a real MusicBrainz recording on the normal accept
path, not the standalone hint.

## Why deferred, not built in T-207

- **Narrow value window.** The hint helps only when Shazam matched, the ISRC did **not**
  resolve (~54% of the time — else Shazam is already a selectable candidate), **and** the
  guess is right. A confident Shazam match usually auto-lands and never parks, so a parked
  card is disproportionately the case where Shazam did not help.
- **It can mislead.** The Strawberry Swing class: Shazam confidently returned *Coldplay* for
  a Frank Ocean cover. Pre-filling re-search with that guess points the owner at the wrong
  answer. A labelled hint is still a confident-wrong suggestion on the card.
- **The gist is already there.** The LLM's `contradictions` text routinely names what Shazam
  thought (e.g. "shazam says Coldplay, disagrees with youtube"), so the owner is not blind.
- **Reversible and cheap to add later.** Wiring it up mirrors T-206 exactly — a persisted
  field emitted on both transports via one shared builder (like `guess_terms`) — so it can be
  added if lived experience shows the owner reaching for a pre-fill button.

## Done when

The Shazam artist/title reaches **both** transports (SSE event + hydrated row) through one
shared builder, is persisted so a reload recovers it, and renders on the card as a **labelled**
hint that feeds re-search / keep-untagged only — never a new landing path (ADR-019/ADR-020).
Graduate this if, after living with T-207, the owner finds the `contradictions` text an
inadequate substitute for a one-click Shazam pre-fill.
