# T-223 — mutagen ID3 writer + art embed

> **Wave 3 of epic [`T-220`](T-220.md) · needs T-222.** Base: **ADR-033** (ratified 2026-08-26).

## Scope

Replace beets' tag-write + `fetchart`/`embedart` in the land tail with a direct **mutagen ID3/MP3-320**
tag+art writer:

- Write artist/album/title (+ year/genre/lyrics when present, per T-222's sourcing) as ID3 frames.
- Download the cover from the accepted identity's `art_url` (Shazam) or the thin `get_recording` (AcoustID
  -only), and embed it (APIC); centre-crop the YouTube-thumbnail fallback to square.
- Adapt muziktest's `real/tagwriter.py` pattern — but MP4→**ID3** is a genuine re-implementation, not a
  copy (MP3-320 is cleanmuzik's ADR-002 output).

## Done when

- A landed MP3-320 carries correct ID3 tags + embedded cover written by mutagen, with no beets tag-write on
  the path.
- The `art_embedded` flag in the `import_song` outcome reflects the mutagen embed, so the review inbox /
  SSE receipts read unchanged.
- Seam tests assert the on-disk ID3 tags + embedded-art presence for a Shazam land, an AcoustID-only land,
  and the thumbnail-fallback case.

## Not

- Do not yet remove beets/plugins from `PLUGINS` (T-224) — this ticket swaps the *writer*; the plugin
  teardown is the last brick so the wave stays reversible until then.
