# T-039 — Inbox loading indicator on cold load

**Status:** untriaged
**Found:** 2026-08-02 (T-102 browser verify)

## Problem

`GET /api/reviews` does a MusicBrainz lookup per candidate on first cold load (the
process-lifetime cache makes subsequent loads fast). During that fetch the inbox shows
"Nothing waiting for review," then pops in the rows once the response arrives. No
spinner, skeleton, or "Loading..." state — it looks like the queue is empty until it
isn't.

A queue with several candidates (5+ per row) can take a few seconds on a cold start.

## Done when

The inbox shows a loading state between mount and the first successful `GET /api/reviews`
response. "Nothing waiting" appears only after the fetch returns an empty array, not
while the fetch is in flight.
