# T-401 — Navidrome as a serving layer alongside Jellyfin

> **Backlog (untriaged).** Filed 2026-08-23. From the Navidrome pivot. Navidrome is a lightweight,
> music-only server that builds its library from **embedded tags on disk** and speaks the **Subsonic
> API** — the ecosystem Symfonium (car) and Feishin (desktop) are built for. CleanMuzik already writes
> cleanly-tagged files, so Navidrome pointed at the same library folder "just works" with **zero
> pipeline change**. Part of the **T-40x listening-layer** set. Infra ticket, not app code.

- **Status:** todo — untriaged. Phased plan option 1 — runs *alongside* Jellyfin, not replacing it yet.
- **The gap.** The library is served only by **Jellyfin** today (PRD "Jellyfin is the hub"; ADR-line).
  Jellyfin is video-first and its best music clients are thinner than the Subsonic ecosystem. Navidrome
  gives the good car clients and is light enough for the eventual always-on box, where Jellyfin would crawl.
- **The shape of a fix.**
  - Stand up Navidrome via Docker (the `~/github/music-stack` compose already has it — **strip SoulSync
    out**, that trial is over; keep Navidrome + the shared `./library` mount, or point Navidrome directly
    at `LIBRARY_DIRECTORY` `read-only`).
  - Navidrome builds artist/album/track from the **tags**, so CleanMuzik's beets tree needs no change.
    Confirm the library browses in Navidrome matching what Jellyfin shows (spot-check the JAŸ-Z /
    credit-fold cases from ADR-028 / T-308).
  - Wire it to consume **T-400's `.m3u8`** for playlists (`ND_PLAYLISTSPATH` / auto-import).
  - **Docker/WSL note:** Docker Desktop's WSL integration must be enabled for this distro first (it isn't
    yet). Container ports publish to the Windows host `localhost`, which is what Tailscale (T-402) exposes.
    Windows reserves 7939–8038, so avoid host-binding in that range (the trial used `8108→8008`).
- **Decision it defers, doesn't make.** Whether Navidrome *replaces* Jellyfin is **T-404**, after real
  car use. This ticket only adds it in parallel — reversible, low-risk.
- **Related:** **T-400** (playlists it serves) · **T-402** (Tailscale reach) · **T-404** (verdict) ·
  `~/github/music-stack` (trial compose, SoulSync to be removed) · PRD §9 hosting · roadmap R3.
- **Done when:** Navidrome runs against the real CleanMuzik library, browses artists/albums/tracks
  correctly from the tags, imports T-400's playlists, and is reachable at `http://localhost:4533` — with
  Jellyfin still running and untouched.
