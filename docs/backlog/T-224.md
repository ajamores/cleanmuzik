# T-224 — Retire beets + drop the slow fetchers

> **Wave 4 (final) of epic [`T-220`](T-220.md) · needs T-221–T-223.** Base: **ADR-033** (ratified
> 2026-08-26, reverses ADR-005). The teardown — do last so the wave is reversible until here.

## Scope

With identity in the senses (unchanged) and tag/art now sourced+written without beets (T-221–T-223), remove
beets and its plugins:

- Drop `musicbrainz`, `chroma`, `fetchart`, `embedart`, `lastgenre` from `PLUGINS` (`app/beets_engine.py`)
  and remove beets itself from the dependency set / engine wiring.
- Move the **AcoustID rescue sense** to the `acoustid` library directly (as muziktest does), not beets
  `chroma`.
- The single AcoustID-only `get_recording` (T-222) uses `musicbrainzngs` directly — so no beets survives.
- **Field rule:** artist/album/title/cover always; year+genre from Shazam when present; lyrics best-effort.
  No standalone fetcher for any field — no MusicBrainz year lookup, no Last.fm, no lyrics plugin.
- Genre auto-writes from Shazam (ADR-033 decision 5); ADR-023's unbuilt LLM-enum genre stays re-homed to
  the deferred polish pass.

## Done when

- beets and the five plugins are gone from the code and deps; the app still lands, dedups (confirm the
  dedup path that lived in beets `choose_item` is preserved or reimplemented — **verify this explicitly**,
  it is the one load-bearing thing beets did beyond tagging), organizes, and sanitizes NTFS-on-WSL paths.
- AcoustID rescue runs via the `acoustid` library; the AcoustID-only tag path via direct `musicbrainzngs`.
- **Epic acceptance (ADR-030/032 bar):** re-run the generalised `t219_compare.py` over the 16-track corpus
  before vs after the whole wave. Prove: materially faster (MB off the common path), artwork present **and
  correct** on landed tracks (Trouble Man = soundtrack cover, not the compilation), identification outcomes
  unchanged modulo the accepted tag-source change, Frank Ocean/Coldplay still parks. Owner-adjudicated.
- Suite green on `main`; ledger + ADR-033 + hot board synced in the closing commit.

## Not / watch

- **Dedup is the trap.** ADR-009's non-destructive acquire-time dedup lived in beets `choose_item`. Retiring
  beets must not silently drop it — carry it forward or the review inbox / duplicate handling regresses.
- Path sanitization (NTFS-on-WSL, `%aunique`, ADR-009/010/015 + T-029) also lived in beets — the same
  carry-forward caution applies.
