# T-221 — Widen the Shazam record to carry the tag payload

> **Wave 1 of epic [`T-220`](T-220.md) · DONE 2026-08-26.** Base: **ADR-033** (ratified 2026-08-26). Full
> rationale lives in the epic + ADR-033; this ticket is the first brick and the seam everything downstream
> reads. Shipped: `album`/`year`/`genre` added to the runner + `shazam.py` §6 record (all keys always
> present, `year` extracted to a 4-digit int); spec §6 amended; 14 new tests; 770 green. Pure capture — no
> behaviour change to identity/voting/fast-path. **Next: T-222.**

## Scope

`app/shazam_runner.py` (the 3.12 subprocess, ADR-024) already returns
`{shazam_artist, shazam_title, isrc, art_url, lyrics, matched, error}`. Add the fields the tag step needs
but the record does not yet keep:

- **album** — from the `track` dict's `sections` metadata.
- **year** — from `sections` metadata ("Released").
- **genre** — `genres.primary`.

All three are already present in the `track` dict the runner fetches from `recognize` — this is capture,
not a new network call. Prefer what `recognize` returns; only call `track_about(track_id)` to fill a field
`recognize` genuinely omitted. Mirror the additions in `app/shazam.py`'s `_RECORD_KEYS` / `_normalise`
(the §6 record shape) so every key is always present and a non-vote still returns the full shape with
`None`s. `art_url`/`lyrics` stay captured-as-today; they become *written* downstream (T-222/T-223), not here.

## Done when

- The Shazam record (both the runner output and `shazam.py`'s normalised §6 record) carries album, year,
  genre alongside the existing fields, all keys always present.
- A matched track populates them from the `recognize` `track` dict; a non-match / timeout / error returns
  the full shape with `None`s (fail-soft unchanged).
- Unit tests over the runner's parse + `shazam.py`'s `_normalise` assert the new fields on a matched fixture
  and their `None`s on a non-vote. No behaviour change to identity/voting — this ticket only widens the
  record.

## Not

- Do **not** write any tag here (that's T-222/T-223). This ticket only makes the data available.
- Do **not** touch the senses gate, the 2-of-3 vote, or the T-219 fast-path.
