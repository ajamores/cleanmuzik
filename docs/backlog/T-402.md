# T-402 — Tailscale + keep-awake: reach the library from the car

> **Backlog (untriaged).** Filed 2026-08-23. The north-star: the owner's music playable **in the car**.
> Tailscale is a mesh VPN (not a VPS) that makes the home machine reachable from a phone anywhere,
> nothing exposed to the public net (PRD §9 phase 1). Part of the **T-40x listening-layer** set. Infra /
> host ticket. Independent of the server choice — it carries **whichever** server wins (Navidrome or
> Jellyfin), so it's buildable now.

- **Status:** todo — untriaged. Phase-0.5 host: the **current laptop** as an always-on box (the 2010
  MacBook is too slow for the heavy migration; see roadmap R3 discussion 2026-08-22/23).
- **The gap.** The library is `localhost`-only. No remote reach, and a laptop sleeps.
- **The shape of a fix.**
  - **Tailscale on Windows** (the server side — Jellyfin/Navidrome ports publish to the Windows host).
    `winget install tailscale.tailscale`, sign in (Google/Gmail). Note the `100.x.x.x` tailnet IP.
  - **Tailscale on the phone**, same account.
  - **Keep-awake** so the laptop is a server, not a nap: Power → plugged-in sleep = *Never*; lid close =
    *Do nothing*. WSL/Docker keep running while Windows is awake.
  - **Car client:** Symfonium (Android) / Amperfy (iOS) → Subsonic server at `http://100.x.x.x:4533`
    (Navidrome) — or Finamp → `:8096` (Jellyfin) if that's the surviving server. **Offline caching**
    matters more than the VPN: download playlists over wifi so dead zones don't stutter.
  - **Firewall gotcha:** Windows Defender may block the server port on the Tailscale adapter — first
    suspect if the phone can't connect.
- **Verify honestly:** test on **cellular with wifi off**, or you haven't proven remote access.
- **Related:** **T-401** (Navidrome, the likely target) · **T-404** (verdict) · PRD §9 · roadmap R3
  (the always-on 2010 MacBook is the *later* dedicated-box upgrade, not this ticket).
- **Done when:** with the laptop plugged in and lid shut, the phone on **cellular** reaches the library
  over Tailscale and plays a track through a Subsonic/Jellyfin client; offline-cached playlists play with
  no signal. Bonus: it works from the car over Bluetooth/CarPlay/Android Auto.
