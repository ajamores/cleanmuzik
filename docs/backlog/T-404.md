# T-404 — Verdict gate: Jellyfin's fate after real car use

> **Backlog (untriaged).** Filed 2026-08-23. The phased plan (option 1) deliberately runs Navidrome
> *and* Jellyfin in parallel, then lets **real car use** decide, not a whiteboard. This is that decision
> gate — the last of the **T-40x listening-layer** set. Not code: a decision, and an ADR reversal if it
> goes Navidrome's way.

- **Status:** todo — untriaged. **Blocked on** T-400 + T-401 + T-402 (need the parallel stack live and
  a week of car listening before deciding).
- **The gap / question.** PRD says "Jellyfin is the hub"; a stack of ADRs and 727 tests are
  Jellyfin-shaped (landing, playlist-by-API, `resolve_item_id`, the T-316 path bridge). If Navidrome
  proves better for the actual goal, keeping the Jellyfin playlist/resolve layer is dead weight — but
  ripping it out is an ADR reversal and drops tested code. **Decide from use, deliberately.**
- **The two outcomes.**
  1. **Keep both.** Navidrome for listening, Jellyfin still served; T-400 writes `.m3u8` *and* the
     Jellyfin API path stays. Simplest to reach, but two servers and playlist code you may not use.
  2. **Navidrome-only, simplify.** Make Navidrome the hub; **retire the Jellyfin API playlist/resolve
     layer** (`jellyfin.py` playlist code, the T-316 path-matching machinery) in favour of
     `.m3u8`-on-disk. Likely **net-deletes code** and kills a whole bug class — but it's a real change,
     reverses "Jellyfin is the hub," and needs its own build ticket + test rework.
- **What to weigh (from the week of use):** did Symfonium/Navidrome actually win in the car? Tag/playlist
  parity confirmed? Is Jellyfin doing anything Navidrome can't (video? something specific)? Does the
  eventual always-on box (slow 2010 MacBook) make Navidrome's lightness decisive?
- **The decision routes, per DoD:** future-code decision → **`adr.md`** (a new ADR or a reversal note on
  the "Jellyfin is the hub" line); scope/intent → the **PRD**; if outcome 2, spawn the retire-Jellyfin
  build ticket into the then-active release.
- **Related:** **T-400 / T-401 / T-402** (the parallel stack this judges) · **T-316** (the Jellyfin path
  complexity outcome 2 would delete) · PRD "Jellyfin is the hub" · roadmap R3.
- **Done when:** the owner has lived with the parallel stack in the car for ~a week and recorded a
  decision (keep-both or Navidrome-only) in the ADR/PRD; if Navidrome-only, a retire-Jellyfin build
  ticket exists in the active release.
