T-310 · R2 Playlists · Design Gate (ADR-016)

The batch view: one aggregate card

Paste a 50-song playlist and walk away. The owner watches it through one card, not fifty — a music journal filling in, not a systems dashboard. These are the flat scenario screens, the ugly states included, for sign-off before any component code (ADR-016). They run in the shipped console skin (ADR-018) — every colour, corner and meter below is the real token from client/src/index.css, not a fresh look.

Stories: US15–US23 · Acceptance items 7, 8 · Encodes ADR-027 (batch/backfill data model) & ADR-028 (artist-credit normalisation) · Reuses the review-inbox resolve seam.

The discipline these screens are proving

  • One card, not fifty. A browser caps ~6 SSE connections per origin; 50 cards would leave 44 streams dead. One card is correctness, not just taste.
  • Warmth over alarms. Parked songs read “still filling in”; failures read “gone / unavailable” — muted, never error-red. The red --danger token appears nowhere on this card.
  • Album art on landed rows only. Parked / gone / queued rows carry no art placeholder — they’d be asserting a cover that doesn’t exist yet (819f22c removed a swatch for exactly this reason).
  • “Needs you” hoisted to the top. The bucket that wants a decision leads; landed / gone / already-here sit below.
  • Parked > 0 ⇒ “waiting on you”, never “done”. A month isn’t finished while messy tracks are unfiled.
  • Zero of zero is “never started”, never “done”. A crash between the row-upsert and the enqueue leaves an empty batch the durable projection calls finished; the card renders the honest state — no green, no red — and points at the safe re-paste.
  • Survives reload & restart. The card rebuilds from durable batch state (T-312), not from replayed memory.

NEW The acquire control — the dial From the design council (2026-08-16). Before the batch card fills, the owner sets intent on a round detented selector — the one round object in a sharp-cornered instrument, a hero control on purpose. It clicks between Single · Playlist · Multi; it never spins (it's an accessible radiogroup, not a knob you drag). The real fix underneath: the app stops guessing intent from URL shape and silently stripping playlists — you say what you mean and the backend honours it. Single is the resting default every load, so the walk-away flow is untouched.
D1 Single — the default, the instant 99% path Every session opens with the dial on Single. Paste a bare song URL, press Go, done — the R1 walk-away flow, byte-for-byte, the selector untouched and unlooked-at. The dial adds no step to the common case.
